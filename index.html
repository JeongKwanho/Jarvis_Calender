JARVIS

A personal calendar assistant · 개인용 일정 비서

JARVIS is a private, single-user assistant that runs on its owner's personal computer. It reads the owner's own Google Calendar so it can show today's schedule and send reminders to the owner.

JARVIS는 소유자 한 명만 쓰는 개인용 비서 프로그램이에요. 소유자의 개인 PC에서 실행되며, 소유자 본인의 구글 캘린더를 읽어 오늘 일정을 보여 주고 미리 알림을 보내요.

  • Not a public service. No sign-up is offered. · 공개 서비스가 아니며 가입을 받지 않아요.
  • Calendar access is read-only. · 캘린더는 읽기만 해요.
  • Data stays on the owner's computer. · 데이터는 소유자의 PC에만 저장돼요.
