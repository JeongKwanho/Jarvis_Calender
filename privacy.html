Privacy Policy · 개인정보처리방침

Last updated: 2026-11-25 · JARVIS home

1. Who uses this app · 사용자

JARVIS is a personal tool used only by its owner. It is not offered to the public.
JARVIS는 소유자 본인만 쓰는 개인용 도구이며, 다른 사람에게 제공하지 않아요.

2. Data accessed · 접근하는 데이터

With the owner's permission, JARVIS reads the owner's Google Calendar events (title, time, location) using the read-only scope calendar.readonly.
소유자가 허용한 경우에만, 읽기 전용 권한으로 소유자의 구글 캘린더 일정(제목, 시간, 장소)을 읽어요.

3. How data is used · 사용 목적

Events are used only to show the owner's schedule and to send reminders to the owner. Data is not sold, shared with third parties, or used for advertising.
일정은 소유자에게 일정을 보여 주고 알림을 보내는 데만 써요. 판매하거나, 제3자와 공유하거나, 광고에 쓰지 않아요.

4. Storage · 보관

Access tokens and data are stored only on the owner's personal computer and are never uploaded to this website.
인증 토큰과 데이터는 소유자의 개인 PC에만 저장되며, 이 웹사이트에는 올라가지 않아요.

5. Google API Services User Data Policy

JARVIS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access · 접근 해제

Access can be revoked at any time at myaccount.google.com/permissions.
위 주소에서 언제든지 접근 권한을 해제할 수 있어요.
